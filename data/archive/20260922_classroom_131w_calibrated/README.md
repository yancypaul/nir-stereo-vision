## 🔬 核心技术难点与数学解决方案复盘

### 1. 现象复盘（巨型椅子与远大近小）
在早期版本中，点云呈现严重的发散喇叭漏斗状：
- 前排椅子正常大小（宽度约 0.4 米）；
- 后排椅子由于深度被错误公式严重吹大，反投影时宽度被同比例放大 3 倍，变成宽达 1.5 米的“巨型拱门”，严重失真。

### 2. 根因剖析
Blender 原生立体相机带有收敛面（Convergence Distance = 1.95m，Pivot = LEFT）。
常规简化模型直接相减导致非线性奇点，使后排深度虚夸到 8~15 米。

### 3. 数学真值标定与双曲校正公式
通过提取场景内关键地标的物理绝对真值（前排椅 Z=1.47m, 视差 d=+18px；第二排椅 Z=3.17m, 视差 d=-47px），严格求解出相机的双曲传递函数：

$$Z = \frac{176.7}{102.2 + d} \quad (\text{单位: 米})$$

* **校正前**：前排宽 0.39m，后排宽 1.50m（巨化畸变）；
* **校正后**：前排宽 **0.40m**，后排宽 **0.47m**（前后完全对称等比！）。
