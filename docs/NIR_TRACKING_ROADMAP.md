## 🗺️ 二、 走向最终成品的“四步走”落地实施计划 (Actionable Roadmap)

为了将系统从“底层核心算法通过”推向“临床/工业级可用成品”，后续需严格按照以下 4 个阶段顺序推进：

### 阶段一：Blender 数字孪生时序动画与闭环精度评估 (本阶段核心)
* **核心目标**：在无需连接真实相机的脱机环境下，利用 Blender 物理级光学渲染，构建 100% 真实物理尺度的近红外动态跟踪基准集。
* **具体任务**：
  1. **光学暗室与探针建模**：纯黑环境（模拟 850nm 窄带滤光片），真实海康相机光学参数（$1280 \times 1024$、双目间距 $60.064\text{ mm}$、$12\text{ mm}$ 镜头），探针装配 4 个高反光球；
  2. **时序轨迹动画设计**：设计 100~200 帧探针在工作空间（物距 $500 \sim 1000\text{ mm}$）内的连续平移、偏航翻转与定点旋转运动；
  3. **自动化双目渲染与真值导出**：自动渲染左、右视角同步序列帧，并逐帧导出探针世界位姿 $[R_{GT} \mid T_{GT}]$ 与针尖绝对物理坐标 $P_{tip}^{GT}$ 为 `trajectory_gt.json`；
  4. **动态误差闭环验证**：编写 `scripts/evaluate_tracking_accuracy.py`，连续解算每一帧，绘制 **帧率曲线 (FPS)** 与 **空间定位误差曲线 (Tracking Error vs Time)**，确认绝对物理定位误差 $< 0.2\text{ mm}$。

### 阶段二：探针尖端摆动标定算法 (Pivot Calibration)
* **核心目标**：摆脱对 CAD 理论尺寸的手工依赖，实现现场换用任意探针均能自标定针尖坐标。
* **具体任务**：
  1. **数学建模**：建立球心拟合最小二乘模型：
     $$R_k \cdot P_{tip}^{local} + T_k = P_{pivot}^{world} \quad (k=1, 2, \dots, N)$$
  2. **定标采集流**：引导操作者将针尖固定在基准小凹坑内，在空间中做圆锥形自由绕转晃动采集 50 帧；
  3. **误差评估与保存**：解算并输出探针刀尖实际偏移向量，计算定标残差（要求 $< 0.15\text{ mm}$），自动覆写/另存为器械配置文件。

### 阶段三：卡尔曼时序平滑与多状态机设计 (Robustness & Anti-Jitter)
* **核心目标**：解决手持生理性微颤，以及大角度倾斜时个别标记球被遮挡导致的跳变闪烁。
* **具体任务**：
  1. **6-DoF 扩展卡尔曼滤波 (EKF)**：对针尖位置 $P_{tip}(t)$ 与四元数姿态 $q(t)$ 进行时序运动滤波，彻底消除高频毛刺；
  2. **抗遮挡与追踪状态机**：
     * `LOCKED` (4 球全见，FRE $< 0.3\text{ mm}$，高精追踪)；
     * `OCCLUDED` (短暂遮挡 1 个球，基于前序速度与刚体先验进行 3 球受限解算或惯性外推)；
     * `LOST` (标记点丢失超 5 帧，平滑淡出并发出声光预警)。

### 阶段四：实时工业/医疗级可视化终端软件 (GUI Finished Product)
* **核心目标**：脱离任何代码与命令行，交付非技术人员双击即可运行的独立桌面应用程序。
* **具体任务**：
  1. **界面布局 (PyQt6 / PySide6)**：
     * **左侧双目视讯流**：实时显示海康左右目红外视频，高亮十字准星实时锁定反光斑质心，实时显示图像采集帧率 (60 FPS)；
     * **右侧 3D 虚拟数字空间**：三维空间视窗同步实时渲染 3D 探针模型，真实人手移动，虚拟探针毫秒级同步跟随；
     * **下方仪表与数据看板**：实时大字显示当前针尖物理绝对坐标 $(X, Y, Z)$、欧拉角姿态及配准误差 FRE 仪表盘；
  2. **交互控制面板**：【连接相机】、【一键尖端标定】、【录制空间轨迹 (CSV)】、【标定误差自检】；
  3. **应用打包**：PyInstaller 打包为单文件 `.exe` 可执行程序。

## 🛠️ 三、 阶段一实施指南：Blender 动画仿真操作手册

### 1. 仿真物理参数规范
| 物理属性 | 仿真设定值 | 对应真实物理硬件 |
| :--- | :--- | :--- |
| **相机分辨率** | $1280 \times 1024$ (5:4 画幅) | 海康 MV-CU013-A0UM 工业传感器 |
| **镜头焦距** | $12.0\text{ mm}$ ($f_{px} \approx 2537\text{ px}$) | 实验室配装的 $12\text{mm}$ 定焦工业镜头 |
| **双目基线** | $60.064\text{ mm}$ (严格水平对齐) | 真实双目铝合金固定支架间距 |
| **环境光照** | 纯黑 (Background Color = 0, Strength = 0) | 850nm 窄带滤光片物理截止可见光 |
| **反光球材质** | 高反光 / 50.0 强度纯白自发光球 | 3M 主动近红外反光标记球 (直径 12mm) |

### 2. 动画关键帧规划 (Trajectory Keyframes)
在工作空间 $Z \in [600\text{ mm}, 900\text{ mm}]$ 内规划一段 120 帧的平滑路径：
* **第 0 ~ 40 帧**：探针沿三维空间 S 弯平移，验证大范围深度变化时的三角交会测距精度；
* **第 41 ~ 80 帧**：探针就地做俯仰（Pitch $\pm 30^\circ$）与翻滚（Roll $\pm 45^\circ$）姿态旋转，验证 SVD 刚体姿态解算的连续性；
* **第 81 ~ 120 帧**：针尖定点不动，探针柄部做伞状圆锥旋转，用于后续 Pivot 标定算法的离线测试验证。
