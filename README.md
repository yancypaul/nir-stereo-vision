# 近红外双目成像系统 (NIR Stereo Vision System)

## 📖 项目简介
本项目致力于构建一个近红外（NIR）双目立体视觉成像与三维重建系统。
支持软硬件解耦设计，具备以下能力：
- **模拟器模式（Mock Camera）**：支持离线图像/视频序列回放，方便脱机调试算法与可视化。
- **工业相机模式（Hik Camera）**：对接海康黑白工业相机 SDK，支持双目硬件/软件同步抓图。
- **立体视觉管线（Stereo Pipeline）**：涵盖相机标定、极线校正、SGBM 视差匹配、点云反投影生成与滤波。
